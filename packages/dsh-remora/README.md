# dsh-remora

Remora の DSH プラグインです。DSH の設定画面に「Remora」タブを追加し、自分の Cloudflare ハブ経由で ChatGPT・Claude・CLI・HTTP API からこの DSH のセッションを操作できるようにします。DeepSeek とは関係のない非公式のプラグインです。

## 入れ方

[GitHub Releases](https://github.com/Aero123421/dsh-remora/releases) から `dsh-remora-<版>.tgz` の URL をコピーし、DSH Web の「Plugins → Add plugin」に貼ります。`SHA256SUMS` で中身を確かめられます。実行時の依存もインストール時のスクリプトもありません。

対応する DSH: `>=0.2.1-alpha.2 <0.2.2-0`

## 使い方

1. 設定 → Remora → 接続 で、ハブの URL を入れて「ペアリングを始める」を押します。
2. 表示された確認コード（QR コードでも可）をハブで確かめ、パスキーで承認します。
3. 権限と範囲を決めます。既定は「見るだけ」で、どのワークスペースも外から触れません。

Plugins 画面の Remora のページと、サイドバー下の小さなチップ（接続状態とワンクリックの緊急停止）からも状態を確認できます。

## 守っていること

- **権限や範囲を広げる変更は、この PC の DSH Web からだけ**: 上限の引き上げ、リモート全権とその延長、緊急停止の解除、ペアリング、ワークスペース・置き場所・コマンドなどの追加、ハブのパスキー変更の承認、質問モードの切り替え、外からの回答の待ち時間をオフから戻すこと、承認を MCP・CLI から許可すること、更新は、ループバック（`localhost`／`127.0.0.1`／`[::1]`）で開いた DSH Web からだけ受け付けます。転送ヘッダー付きのリクエストはループバック扱いにしません。狭める変更と緊急停止はどこからでもできます。
- **リモート全権**は確認ダイアログを経て有効になり、24 時間で「依頼できる」に戻ります。危険な操作はペアリング時に固定したパスキーの署名をこの PC で検証します。
- DSH のサンドボックスが制限するのは書き込みだけで、読み取りとネットワークは制限しません。
- **スキル・エージェントプリセット・スラッシュコマンドは、設定タブでオンにしたものだけ**が外から使えます。リモート全権でもこの一覧は広がりません。権限プリセット（`/permission`）、送信・エクスポート（`/feedback`・`/export`）、プラグイン・資格情報・ログイン・Remora 自身に関わるコマンドは、オンにすることもできません。エージェントプリセットは権限プリセットを持たず、新しいセッションは DSH 既定の権限で始まります。
- **スキルの許可リストは、信頼済みのワークスペースでは目安です**: DSH はプロンプトの文中で名前を挙げただけのスキルもモデルに読み込ませられるため、`/name` の検査だけでは止めきれません。そこで Git からクローンしたワークスペース（信頼していないワークスペース）へは、設定タブの「範囲 → 信頼していないワークスペース」で「信頼する」を押すまで、タスクの投入と追加指示を拒否します。
- **Git クローンはバックグラウンドで実行**します。`workspace.create` はすぐに `state: "cloning"` で返り、`workspaces.list` で `ready`／`clone-failed` を確認できます（10 分・サイズ上限つき。失敗したらフォルダと登録を消します）。クローン中のワークスペースへのタスクは `conflict` で拒否します。

## 保存場所

- 設定・ペアリング状態・タスク台帳・監査ログ（ハッシュ連鎖、本文は残さない）: `$DSH_HOME/storages/dsh-remora/`（既定は `~/.dsh/storages/dsh-remora/`）。ファイルは 0600。
- ホストの Ed25519 秘密鍵: DSH の資格情報ストア（`$DSH_HOME/.credentials.yaml` のレコード `dsh-remora/host-key`）。平文の YAML で、ファイルの権限（0600）だけで守られます。資格情報サービスが無い DSH では、データフォルダーの `host-key.json`（0600）に置きます。
- 同じ `$DSH_HOME` で DSH を複数起動しても、ハブにつなぐのは 1 つだけです（`hub.lock`）。

## ペアリングの解除

「ペアリングを解除」は、ホスト鍵で署名した解除要求をハブ（`POST /pair/unpair`）に送ってから、この PC の鍵とペアリング状態を消します。ハブに届かなかったり拒否されたりした場合も手元では解除し、タブに「ハブのホスト一覧から削除してください」と出します。鍵を作り直したいときは「鍵を作り直して再ペアリング」を使います（承認されるまでは今の鍵のままです）。

## 質問・プランの確認・承認に外から答える

Remora は DSH の質問（`user-questions/request`）と承認（`approval/request`）の受け付けの先頭に入り、DSH Web などほかの受け手に回しながら、外（ハブ・MCP・CLI）からの回答と競わせます。先に答えた方が採用され、外からの回答が勝ったときは DSH Web の画面を閉じさせます。

- **待つ時間**（権限タブ「外からの回答を待つ時間」、既定 10 分、0 でオフ）: DSH Web が開いていない、またはほかに答えられる受け手がいないとき、Remora はこの時間だけ外からの回答を待ちます。誰も答えなければ DSH は回答なしで続けます（質問は「回答なし」、承認は拒否扱い）。DSH Web が開いている間は締め切りを付けず、これまでどおり DSH Web の画面も待ちます。オフから戻すのはこの PC からだけです。
- **承認**: 既定では、ハブの要対応ページでオーナーのパスキーを使って答えます（DSH 側で署名を検証します）。MCP・CLI から `approval.respond` を送ると、そのページへのリンク付きで断ります。「承認を MCP・CLI からも許可する」をオンにすると（この PC からだけ）、「依頼できる」権限のクライアントがパスキーなしで承認・拒否できます。
- 受け付けるのは、ハブにつながっていて、緊急停止がオフで、上限が答える操作（`attention.respond`／`approval.respond`）を許し、セッションが範囲内で、ワークスペースが信頼済みのときだけです。それ以外は DSH にそのまま渡します。
- 要対応の項目には、答え方（`answerVia`: `remote`／`hub-passkey`／`dsh-web`）と締め切り（`expiresAt`）が付きます。

`tool-ask-user` の `timed` モードの質問は、これまでどおり時間切れで「あとで回答」になってから `userQuestions.answer` で答えます。権限タブにプリセットごとのモードを表示し、この PC からなら「すべてのプリセットを timed に切り替える」で切り替えられます（任意）。

## 検索・フォーク・ジョブ・スケジュール・ターミナル

- **会話の検索**（`sessions.search`、`dsh.content` が必要）: DSH Web の全文検索はオフで出荷されているため、範囲内のセッションのログをセッションを起こさずに新しい順に読みます。1 回 300 セッション・8 秒まで、超えたら途中までの結果（`partial`）を返します。
- **フォーク**（`session.fork`、依頼できる）: 指定ターンの終わりまでを写した新しいセッションを同じワークスペースに作ります。サブエージェントのセッションは対象外です。
- **バックグラウンドジョブ**: `session.get` に範囲内のセッションのジョブ（コマンド行は `dsh.content` があるときだけ）が出ます。`job.output` で出力を読み、`job.stop`（依頼できる）で止めます。止めた理由には Remora 経由であることとクライアント名を残します。ジョブが動いている間、そのタスクは「実行中」のままです。
- **スケジュール**（DSH の自動タスク）: 一覧（`schedules.list`、依頼文は `dsh.content` があるときだけ）、追加（`schedule.create`、依頼できる）、削除（`schedule.delete`）。時間になると DSH がそのセッションに依頼として送るので、追加はタスク投入と同じ条件（範囲内・信頼済みで準備済みのワークスペース・アーカイブしていない通常のセッション）でだけ受け付けます。
- **ターミナル**（`terminal.run`、リモート全権）: ワークスペースのフォルダで、DSH の `ctx.subprocess` を使ってコマンドを 1 回実行します（資格情報らしい環境変数は DSH が除きます）。DSH のサンドボックスの外で、DSH と同じユーザーとして動きます。毎回、ハブでオーナーがパスキーで確認した署名をこの PC で検証してから動かします。既定 60 秒・最長 10 分で止め、出力は各 64 KB まで、シークレットらしい文字列を伏せて返します。

## プロキシ

Node 22 の標準 WebSocket は、DSH を `NODE_USE_ENV_PROXY=1` 付きで起動したときだけ `HTTPS_PROXY`／`HTTP_PROXY` を通ります（Node 22.21 以上）。プロキシ変数があるのにこの指定が無いと、タブに警告を出します。

詳しくは[リポジトリの README](https://github.com/Aero123421/dsh-remora#readme) を見てください。
