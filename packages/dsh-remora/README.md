# dsh-remora

Remora の DSH プラグインです。DSH の設定画面に「Remora」タブを追加し、自分の Cloudflare ハブ経由で ChatGPT・Claude・CLI からこの DSH を操作できるようにします。

> まだ準備中の版です。今はタブで状態と緊急停止を確認できるだけで、ハブとのペアリングは次の版で追加します。

## 入れ方

[GitHub Releases](https://github.com/Aero123421/dsh-remora/releases) から `dsh-remora-<版>.tgz` の URL をコピーし、DSH Web の「Plugins → Add plugin」に貼ります。`SHA256SUMS` で中身を確かめられます。

対応する DSH: `>=0.2.1-alpha.2 <0.2.2-0`

詳しくは[リポジトリの README](https://github.com/Aero123421/dsh-remora#readme) を見てください。DeepSeek とは関係のない非公式のプラグインです。
