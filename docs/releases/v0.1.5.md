# v0.1.5

タスク完了・要回答を待つ操作の応答性を保ちながら、Cloudflare の Durable Objects を待機中に休止できるようにします。パスキーの復旧、複数 DSH プロセスからの自己更新、権限変更を取り消した後の表示も修正します。

## 変更

- タスク・確認結果の長時間待機は Worker 側で通知を待ち、Durable Object 内に待機タイマーを保持しません。応答直前に権限を確認します。
- 使用量の概算が対象にしていない上限を明示し、WebSocket の使用量カウンターを休止の前後で保持します。
- リカバリーコードでログインした直後は、失ったパスキーを要求せず、新しいパスキーを登録できます。
- 権限変更のパスキー確認を取り消した場合、画面を保存済みの値へ戻します。送信エラー時は依頼・スケジュールの入力を保持します。
- 同じ profile を使う複数プロセスで更新処理の所有権を共有し、進行中の更新を中断扱いにしたり二重実行したりしないようにします。
- 設定の通信失敗と古い情報を区別し、アクティビティの読み込み・失敗・空状態を表示します。画面を隠している間は定期取得を止め、戻ったときに再取得します。
- 保存データの初期化に失敗した場合も診断を表示し、監査ログの追記時に同じ内容を毎回全検証する負荷を減らします。
- MCP の権限不足時の案内、操作の副作用の注釈、通信の期限と取消を改善します。
- ハブ同期 PR の作成失敗を再試行できるようにし、最新の対応 DSH を RC を含めて選び、最低対応版とともにリリース前に検証します。

## 更新と費用

プラグイン・CLI・ハブの版番号は 0.1.5 です。Cloudflare への自動デプロイや有料契約への変更は行いません。各自のハブは同期 PR または `hub/` の再デプロイで更新します。

追加課金を避ける場合は Workers Free を維持してください。無料枠を超えた操作は失敗することがあります。既存の Paid アカウントにはその契約の料金が適用され、このソフトウェアや概算メーターだけで料金をゼロに固定することはできません。

通知待機は DO の実行時間を減らす一方、保留する待機 1 回の HostDO 呼び出しが 1 回から 3 回へ増えます。25 秒待機を終日繰り返す場合は、1 ホスト約 10,368 回／日に認証等が加わります。待機用の定期ポーリングや SQL 行の保存はありません。

## 検証

型検査、プラグイン・CLI のビルド、ハブのデプロイなしのバンドル検証に成功しました。プロトコル・CLI・プラグインの 474 テスト、ハブの 89 テスト、リリース選択・同期の 10 テストが通っています。最新版 DSH 0.2.1-rc.2 の実ソースを使うアダプター検証も 16 テストが通っています。

npm 配布の DSH 0.2.1-alpha.2（対応下限）と 0.2.1-rc.2 で、プラグインの導入からブラウザー・ハブ・複数 DSH プロセスまでの通しテストがそれぞれ 45 件成功、失敗・スキップ 0 件です。パスキー全喪失後の復旧と権限変更の取消も含みます。workerd では待機中の DO を実際に休止させ、状態変化によって即時応答することを確認しています。

実 Cloudflare の使用量・課金、実 ChatGPT／Claude 接続、実機の消費電力はこの検証に含めません。
