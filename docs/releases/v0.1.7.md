# v0.1.7

DSH の設定にある Remora の文言を、ブラウザーの言語が日本語のときに日本語で表示します。設定欄が狭いときに、接続状態やタブ名が単語の途中で折れたり、入力欄が内容欄の外にはみ出したりしないようにします。

## 変更

- 言語一覧に `ja`（日本語）がまだ無いときだけ、Remora がその言語を登録します。表示文は今までどおり Remora 自身の辞書です。dsh-japanese などが先に `ja` を登録している場合は、Remora は言語定義を追加も削除もしません。Remora を外すと、Remora が登録した `ja` と Remora の辞書だけを外します。
- 設定内容の幅が 360px 以下のとき、状態と操作ボタンを縦に並べ、タブ名は空白と日本語の文字境界で折り返します。URL は幅の中で折り返します。入力欄は内容欄の幅に合わせます。それより広い設定欄の並びは 0.1.6 のままです。

## 更新

プラグイン・CLI・ハブの版番号は 0.1.7 です。既存の設定、ペアリング、個人トークンは引き継ぎます。この版の修正はプラグインの設定画面だけです。ハブの再デプロイは不要です。
