# v0.1.7

設定欄が狭いときに、接続状態、タブ名、ボタン、緊急停止の文言が単語の途中で折れたり、入力欄やボタンが内容欄の外にはみ出したりしないようにします。

## 変更

- ビューポートが 480px 以下のとき、このプラグインのスタイルは設定ダイアログの左ナビを上へ移します。DSH のナビ幅 188px のままだと、320px では Remora の内容欄が約 36px になり、「Connected」や「Open configuration file」の configuration が収まりません。ナビを上に置くと内容欄が広がり、単語は空白で折り返します。この指定はプラグインのスタイルシートにあり、プラグインを外すと消えます。600px 以上の左右並びは変えません。
- 設定の文言は `overflow-wrap: break-word` です。`anywhere` は最小幅を 1 文字にするため使いません。URL と識別子だけ `.rmr-mono` の `word-break: break-all` で折り返します。説明の列は基準幅 `12rem` です。内容幅が 360px 以下のときは行を縦に並べます。ホスト名の入力は幅 100%、最小幅 0 です。
- 言語 `ja` が未登録のときだけ `addLanguage({ id: 'ja', label: '日本語', fallback: 'en' })` を呼び、そのあと辞書を登録します。dsh-japanese が先に `ja` を登録しているときは追加しません。その `ja` は Remora を無効にしても残ります。Remora だけが `ja` を追加していた場合は、無効化でその定義が外れ、表示は英語に戻ります。登録 API が要求する `zh` には英語の辞書を渡します。中国語では Remora の文言は英語です。

## 更新

プラグイン・CLI・ハブの版番号は 0.1.7 です。既存の設定、ペアリング、個人トークンは引き継ぎます。この版の修正はプラグインの設定画面だけです。ハブの再デプロイは不要です。

## 検証

DSH `0.2.1-rc.2` に、このリポジトリで作った `dsh-remora-0.1.7.tgz` を `dsh plugin --profile web add` で入れる。`github:` 指定は README が案内していないので使わない。

- `locale-register` は、`ja` が無いときだけ言語を追加すること、dsh-japanese が先に `ja` を持っているときは Remora を外しても `ja` と日本語が残ること、Remora だけが追加した `ja` は無効化で外れ英語に戻ることを確認する。中国語では Remora の文言が英語になることも確認する。
- 接続中の設定を 320px・390px・768px・1280px、明暗で開き、接続状態・URL・ホスト名の入力・緊急停止が同じ画面に写ることを確認する。
- `node e2e/run.mjs --dsh-version=0.2.1-rc.2 --strict` の結果は、この版の確認が終わってからこの節へ追記する。

Cloudflare へのデプロイと、この版の GitHub Release は作っていない。
