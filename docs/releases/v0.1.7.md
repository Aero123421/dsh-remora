# v0.1.7

設定欄が狭いときに、接続状態、タブ名、ボタン、緊急停止の文言が単語の途中で折れたり、入力欄やボタンが内容欄の外にはみ出したりしないようにします。

## 変更

- ビューポートが 480px 以下のとき、このプラグインのスタイルは設定ダイアログの左ナビを上へ移します。DSH のナビ幅 188px のままだと、320px では Remora の内容欄が約 36px になり、「Connected」や「Open configuration file」の configuration が収まりません。ナビを上に置くと内容欄が広がり、単語は空白で折り返します。この指定はプラグインのスタイルシートにあり、プラグインを外すと消えます。600px 以上の左右並びは変えません。
- 設定の文言は `overflow-wrap: break-word` です。`anywhere` は最小幅を 1 文字にするため使いません。URL と識別子だけ `.rmr-mono` の `word-break: break-all` で折り返します。説明の列は基準幅 `12rem` です。内容幅が 360px 以下のときは行を縦に並べます。ホスト名の入力は幅 100%、最小幅 0 です。
- Remora は言語 `ja` を定義しません。`addLanguage` は呼びません。`en`、`ja`、`zh` の辞書を、ロケールごとに登録します。日本語の表示には dsh-japanese が必要です。それが無いとき、言語メニューに「日本語」は出ず、Remora の文言は英語です。簡体字中国語では `zh` の辞書を使い、文言は中国語です。キー名は出しません。dsh-japanese と Remora を両方外したあとは、外した順にかかわらず `ja` の定義は残りません。

## 更新

プラグイン・CLI・ハブの版番号は 0.1.7 です。既存の設定、ペアリング、個人トークンは引き継ぎます。この版の修正はプラグインの設定画面だけです。ハブの再デプロイは不要です。

## 既知の問題

pnpm 12 でプラグインを追加・更新すると、プロファイルの lockfile に公開から24時間たっていない依存が含まれている場合、ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION で失敗することがあります。このとき pnpm がプロファイルの node_modules を空にし、DSH も元に戻さないため、同じプロファイルのすべてのプラグインが読み込まれなくなります。プラグインの追加・更新は pnpm 10 で行ってください。壊れたときは pnpm 10 で `dsh plugin --profile web install` を実行すると戻ります。pnpm 11 では ERR_PNPM_UNEXPECTED_STORE で止まりますが、node_modules は壊れません。

REM-3（P3）。ハブが使う `@cloudflare/workers-oauth-provider` 1.2.3 の `OAuthResourceServer` は、Authorization に Bearer トークンが無いとき、または `validateToken` の戻りが有効なトークンオブジェクトでないとき、本文のない 401 を返す。`WWW-Authenticate` は付き、JSON の `error` 本文は付かない。CLI の HTTP API は本文が空なら `body` を `null` にする。401 で本文に `error.code` と `error.message` が無いため、標準エラーには `remora: ハブが認証を受け付けませんでした。` と、次の行 `remora login でログインし直してください。` が出て、終了コードは 4 になる。`--json` の `error` は `code` が `unauthorized`、`message` が「ハブが認証を受け付けませんでした。」、`hint` が「remora login でログインし直してください。」、`exitCode` が 4 である。`REMORA_TOKEN` ではなく refresh token があるときは、この本文を読む前にトークンを一度更新して同じ要求を送り直す。送り直した応答も本文のない 401 なら、同じ表示になる。`remora mcp` は空の本文を JSON として読めず、詳細を足さない。JSON-RPC エラーの `message` は `Remora: ハブがエラーを返しました（HTTP 401）。remora login でログインし直してください` になる。`WWW-Authenticate` の値はこの文に入らない。これは次の版で直す。

`github:Aero123421/dsh-remora#v0.1.7` を指定した導入は確かめていない。プラグインを入れるときは、Release に付いた `dsh-remora-0.1.7.tgz` の URL を使う。
