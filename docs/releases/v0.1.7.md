# v0.1.7

設定欄が狭いときに、接続状態、タブ名、ボタン、緊急停止の文言が単語の途中で折れたり、入力欄やボタンが内容欄の外にはみ出したりしないようにします。

## 変更

- ビューポートが 480px 以下のとき、このプラグインのスタイルは設定ダイアログの左ナビを上へ移します。DSH のナビ幅 188px のままだと、320px では Remora の内容欄が約 36px になり、「Connected」や「Open configuration file」の configuration が収まりません。ナビを上に置くと内容欄が広がり、単語は空白で折り返します。この指定はプラグインのスタイルシートにあり、プラグインを外すと消えます。600px 以上の左右並びは変えません。
- 設定の文言は `overflow-wrap: break-word` です。`anywhere` は最小幅を 1 文字にするため使いません。URL と識別子だけ `.rmr-mono` の `word-break: break-all` で折り返します。説明の列は基準幅 `12rem` です。内容幅が 360px 以下のときは行を縦に並べます。ホスト名の入力は幅 100%、最小幅 0 です。
- 言語 `ja` が未登録のときだけ `addLanguage({ id: 'ja', label: '日本語', fallback: 'en' })` を呼び、そのあと辞書を登録します。dsh-japanese が先に `ja` を登録しているときは追加しません。両方入っているときは、Remora が先に `ja` を追加していても、無効化または削除ではその定義を外しません。dsh-japanese が `common` または `settings` に `ja` の辞書を残しているあいだ、DSH 本体は日本語のままです。Remora だけのときは、無効化でその定義が外れ、表示は英語に戻ります。型付きの一括 `register` は `zh` 辞書を要求するので使わず、`en` と `ja` をロケールごとに登録します。簡体字中国語は組み込みの `zh` が `en` にフォールバックし、Remora の文言は英語です。キー名は出しません。

## 更新

プラグイン・CLI・ハブの版番号は 0.1.7 です。既存の設定、ペアリング、個人トークンは引き継ぎます。この版の修正はプラグインの設定画面だけです。ハブの再デプロイは不要です。

## 検証

DSH `0.2.1-rc.2` に、このリポジトリで作った `dsh-remora-0.1.7.tgz`（sha256 `16de45e268e23166e8f203becc955422fd990253f2e781b7671666fb8ca25510`）を `dsh plugin --profile web add` で入れた。dsh-japanese 0.2.2 は同梱の tarball を同じコマンドで入れた。`github:` 指定は README が案内していないので使っていない。`npm i -g` は使っておらず、隔離ディレクトリへ入れた rc.2 の cache を使った。`@aws-sdk/credential-provider-http` の notarget は出ていない。

- `pnpm typecheck`（`tsc -b`）は成功した。`pnpm --filter dsh-remora test` は 364 件成功した。`locale-register` のテストは `addLanguage({ id: 'ja' })` を呼ばない。カタログに `ja` が無い状態から `installLocale` だけで「日本語」が追加され、`zh` を選ぶと Remora の文言は英語になり、キー名は出ない。そのあと `zh` 辞書を登録できるので、Remora 自身は `zh` を登録していない。言語追加を外した修正前の `installLocale` で同じ検査を走らせると、`ja` の項目が `undefined` のままになり失敗する。残りの検査は、dsh-japanese が先に `ja` を持っているときは Remora を外しても `ja` と「設定」が残ること、Remora が先に `ja` を追加したあと dsh-japanese が `common` と `settings` の `ja` を登録した場合も Remora を外すと `ja` と「設定」「キャンセル」が残ること、Remora だけが追加した `ja` は無効化で外れ表示が英語に戻ること、表示する文言は英語と日本語の両方があることを確認している。
- ブラウザ言語 `zh-CN`、Remora だけで DSH `0.2.1-rc.2` を開いた。設定の Remora は明暗とも英語で、「Kill switch」「Connection」「Not paired with a hub yet.」「Hub URL」が出て、`kill.title` や `conn.notPaired` は出ていない。DSH 本体は簡体字中国語のまま（アカウントメニュー「账号菜单」、設定「设置」）。画面は `zh-CN-remora-light.png` と `zh-CN-remora-dark.png`。言語メニューには「中文」「English」「日本語」があり（`zh-CN-language-menu.png`）、Remora 単体で「日本語」を選ぶと Remora の文言は「緊急停止」「接続」になる（`zh-CN-then-ja-remora.png`）。本体の `ja` 辞書は Remora が持たないので、この選択のあと本体の表示は英語になる。本体を日本語にするには dsh-japanese が必要。
