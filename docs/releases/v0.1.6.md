# v0.1.6

ハブを日本語・英語・簡体字中国語で使えるようにし、画面を DSH Web に合わせた明暗のデザインへ刷新します。プラグインの導入から最初のタスクまでの案内も改善します。

## 変更

- ブラウザーの言語を使い、画面下の切り替えで選んだ言語を保存します。エラーと対処方法、パスキー操作、通知の文面も翻訳しました。
- 日時を閲覧端末のタイムゾーンで表示します。サーバーが返す日時は UTC です。
- ホームにペアリング、ワークスペース範囲の許可、クライアント接続、最初のタスクの手順を表示します。到達できるワークスペースがあるか確認し、ペアリング直後の接続待ちを自動更新します。
- プラグインとハブの URL のコピー、CLI の導入、Claude Code の認証、個人トークンの発行、Cloudflare へのデプロイ手順を案内します。
- セッションの追加指示は実行中のターンがある場合に表示します。OAuth の接続許可では、Remora CLI 以外の管理スコープを既定で選択しません。
- ホストから受け取るエラーの対処リンクは、ハブ内のパスだけを開くようにしました。

## 更新

プラグイン・CLI・ハブの版番号は 0.1.6 です。既存の設定、ペアリング、個人トークンは引き継ぎます。通知の言語を保存する列をハブの起動時に追加します。既存の通知購読は端末の言語を使い、再登録すると画面の言語を保存します。

ハブの改善を使うには、自分のハブの同期 PR をマージするか、`hub/` を再デプロイしてください。GitHub Release の公開だけでは利用者の Cloudflare 環境は更新されません。

## 検証

型検査、プラグイン・CLI のビルドと配布 tarball の作成、プロトコルのコピーの一致、ハブのデプロイなしのバンドル検証に成功しました。プロトコル・プラグイン・CLI の 474 テスト、ハブの 99 テスト、リリース選択・同期と版番号の 11 テストが通っています。対処リンクの回帰テストは元の PR では失敗し、修正後に成功することを確認しました。

npm 配布の DSH 0.2.1-alpha.2（対応下限）で、導入・ブラウザー・承認・タスク・複数プロセスの通しテストが 45 件成功、失敗・スキップ 0 件です。ハブの 7 画面について、3 言語 × 明暗 × 幅 430px / 1280px の計 84 パターンをブラウザーで開き、横にはみ出す表示やスクリプト例外がないことを確認しました。通知スクリプトの 3 言語と既存購読向けの言語選択も確認しています。

リリースの GitHub Actions は、対応下限と最新の対応 DSH で厳密モードの通しテストを実行し、5 種類の CLI 実行ファイルを各 OS でビルドしてから公開します。

実 Cloudflare へのデプロイ、実機の iOS / Android の通知表示、実 ChatGPT / Claude 接続は検証に含みません。
